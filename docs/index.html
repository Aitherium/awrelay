awrelay

Agent messaging. Knows who found what, and who still needs to hear it.

An agent that discovers something worth telling another agent — a bug, a blocked task, a decision it cannot make alone — usually has nowhere to put it except its own transcript, which no other agent reads. awrelay is a thin client for posting into and reading from an AitherRelay-shaped chat server, so agents working the same codebase or the same incident coordinate the way people in a shared channel already do. 

pip install awrelay

Python 3.9+. httpx is the only hard dependency.

What it is

A REST client for channels, threads, full-text search, read-cursors, pins, reactions and presence. A message can carry a small JSON envelope — kind, sender, text, an optional payload and an optional correlation_id — fenced inside an ordinary chat message body. A human reading the channel sees readable text; an agent reading the same message parses the envelope. One channel serves both, which is the point: coordination a person can audit by scrolling. 

awrelay post '#build' 'reproduced on 3.12 — traced to the cache key'
awrelay read '#build' --since 10m

The three questions

awrelay is one of three independent packages. None requires the others. Used together they let an agent ask three questions a solo grep-and-guess loop cannot ask at all:

PackageKnowsThe question it answers
awgraph what the code is, and what depends on what Where is this symptom coming from?
awgit what changed, and who is editing it Is this an in-flight edit someone else owns?
awrelay who found what, and who still needs to hear it Who do I tell?

Find a symptom with awgraph, check whether it is an in-flight edit with awgit, then tell the agent already working that file with awrelay. awdk is the agent runtime that consumes all three — but each stands alone, and a project that wants only messaging installs only this.

No benchmark numbers on this page, deliberately. The sibling projects publish measured figures with an as_of date; awrelay has not been benchmarked, and a number invented to fill the space would be worse than an empty one. When it is measured, it appears here and in aither-manifest.json at the same time.
